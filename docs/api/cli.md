# Command line

The options of `pysovist isovist` and `pysovist volume`, and the environment variables of `pysovist odtp`, are listed in the [quick start](../quickstart.md#command-line). `pysovist --help` and `pysovist <command> --help` print the options of the installed version.

::: pysovist.cli
    options:
      show_root_full_path: true
