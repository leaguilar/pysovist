# DeCodingSpaces compatibility

Functions that reproduce the numbers of the DeCodingSpaces Isovist and Isovist3D components for Grasshopper. The
[DeCodingSpaces compatibility](../decodingspaces.md) page explains each property and how it differs from pysovist's
standard metrics.

::: pysovist.compat.decodingspaces
    options:
      show_root_full_path: true

::: pysovist.compat.decodingspaces3d
    options:
      show_root_full_path: true
